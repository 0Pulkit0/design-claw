| # | Role (UI label) | Capture | Suggested source | Contributes |
|---|---|---|---|---|
| 1 | Base reference (spine) | the article body column | any clean reader / blog post | measure (width) + spacing + base type |
| 2 | Typography source | the article H1 title | a publication with a strong display face | font family / size / weight / line-height |
| 3 | Color source | body text + a link | the same or another reader | palette (text color, link color) |
| 4 | Shape source | the pull-quote block or an inline code chip | any bordered/rule-marked block | border, radius |
